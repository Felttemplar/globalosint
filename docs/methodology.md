# Princípios metodológicos

- Fontes recém-cadastradas começam como `candidate`; cadastro não implica confiança ou aprovação.
- A avaliação de confiabilidade é um juízo documentado sobre a fonte, não uma probabilidade matemática de verdade.
- Confiança da avaliação e gravidade potencial do evento são campos separados.
- `fact`, `report`, `inference` e `hypothesis` distinguem observação verificada, relato atribuído, interpretação e possibilidade investigativa.
- Contagens de republicações não equivalem a confirmações independentes. `origin_group` permite futuramente agrupar cadeias de republicação.
- Evidência precisa guardar URL, fonte, data de coleta, hash opcional e avaliação de suporte/contradição.
- Conteúdo externo é dado não confiável e nunca deve ser tratado como instrução executável.
- Coleta em redes sociais só deve usar conteúdo público e meios autorizados; esta versão não implementa coleta social.
- Ainda não existe método automatizado validado para pontuação de eventos, anomalias ou cenários. Esses campos permanecem sem preenchimento até uma etapa própria.
